# Mini Project
Kumpulan projek-projek kecil singular berbasis Text User Interface (TUI).

### Judi Text User Interface (Judi TUI)
Program simulasi di mana user memasukkan nominal uang untuk melakukan judi dengan konsep acak 2 dadu dan mengharuskan kedua dadu bernilai sama untuk menang.
- **Materi:** Input/Output, Variabel & Tipe Data, Konstanta, If-Else, Operator Matematika, RNG.
### BaKeGun (Batu Kertas Gunting)
Program mengacak pilihan player 1 dan player 2 lalu mengadu Batu, Kertas, dan Gunting untuk menentukan pemenang.
- **Materi:** RNG, Nested If.
### Pohon Custom
Program untuk memunculkan pola karakter bintang (`*`) yang membentuk pohon dengan ketinggian dinamis (maksimal 51).
- **Materi:** Nested Loops.
### Video PLayer
Program mengkomunikasikan kepada windows untuk memutar video via terminal.
- **Materi:** ctsdlib, system("").
