# Belajar-Cpp
Repository dimana aku belajar dan mempraktekkan apa yang telah kupelajari tentang bahasa C++.  
Repository ini dibuat sebagai tempat mengumpulkan hasil akhir dari projek-projek yang pernah kubuat.

## Strategi Belajar
1. **Mempelajari 1 konsep/materi baru**
2. **Mencari ide**: Mencari ide projek sebagai praktik materi yang kupelajari saat itu
3. **Mencoba membuat kodingan sendiri**: Mencoba membuat program tanpa lihat contoh, referensi kode dengan tujuan melatih pemahaman sendiri.
4. **Evaluasi**: Mengevaluasi program yang sudah dibuat dengan cara melihat referensi kode atau tanya AI.
5. **Pelajari ulang**: Mempelajari apa yang berbeda dan apa yang masih bisa diperbaiki dari programku.
6. **Menulis ulang kode**: Memperbaiki kode yang sudah dibuat dengan hasil evaluasi dan mempelajari ulang referensi.
7. **Push ke Github**: Push hasil akhir ke repository ini
